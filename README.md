# Zippa — Mobilidade e Delivery

Site institucional completo da Zippa com 3 páginas, design mobile-first, animações e copywriting persuasivo.

## Páginas

| Arquivo | Descrição |
|---|---|
| `index.html` | Homepage com split screen interativo |
| `mobilidade.html` | Página Zippa Mobilidade |
| `delivery.html` | Página Zippa Delivery |
| `css/style.css` | Estilos globais |
| `js/main.js` | Interatividade e animações |

## Funcionalidades

- ✅ Split screen interativo na homepage
- ✅ Navbar fixa com efeito scroll
- ✅ Menu mobile responsivo
- ✅ Animações de scroll (IntersectionObserver)
- ✅ Contador animado nas estatísticas
- ✅ Botão flutuante WhatsApp
- ✅ Design mobile-first
- ✅ Seção de motoristas e restaurantes parceiros
